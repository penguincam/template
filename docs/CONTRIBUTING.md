# Contributing

This repository follows the organization
[contributing guide](https://github.com/penguincam/.github/blob/main/CONTRIBUTING.md).
Fork it as `<repo>-contrib`, run `just fork-setup <your-login>` and
`just hooks-install`, and send pull requests into `dev`.

Every commit is signed and signed off. One command does both:
`git commit -S -s`. The contributing guide says what the sign-off certifies.
